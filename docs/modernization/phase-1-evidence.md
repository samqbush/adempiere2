# Phase 1: Reproducible core safety gate

## Scope

Phase 1 moves the core Gradle path from L1 to L3. It does not change production
behavior, database schema, runtime deployment, Maven coordinates, or release
artifact names. The Ant distribution path and all surfaces listed in
`gradle/phase1/quarantine.txt` remain outside the Gradle gate.

## Compatibility decisions

- `:serverRoot` is the only `options.release = 11` exception. Its JDK-internal
  LDAP imports require `--add-exports`, so it uses Java 11 source/target
  compatibility and the class-file verifier.
- The `:base` test runtime privately uses Mockito 4.11.0 and explicit JUnit
  Platform/Jupiter components on JDK 17. The published
  `io.github.adempiere:adempiere.test` dependency contract remains unchanged.
- `UT_ImpFormat` and `UT_MPriceListVersion` were reclassified as integration
  tests because both require Garden World database state.
- `TestDocumentEngine` now derives the invoice table ID from the production
  model constant, removing a test-order/database initialization dependency.

## Reproduction

```bash
ADEMPIERE_LIBRARY_VERSION=phase1 ./gradlew build cyclonedxBom \
  verifyProjectTopology verifyJavaCompatibilityExceptions \
  verifyJava11Bytecode verifyTestClassification verifyTestResults \
  verifyPublicationContracts --dependency-verification=strict

scripts/phase1/verify-mutation.sh

JAVA_HOME=/path/to/jdk-11 \
  PATH="$JAVA_HOME/bin:/path/to/ant/bin:$PATH" \
  ant -f tools/build.xml
JAVA_HOME=/path/to/jdk-11 \
  PATH="$JAVA_HOME/bin:/path/to/ant/bin:$PATH" \
  ant -f base/build.xml unit-tests
```

The Ant `tools` target creates the existing `lib/CCTools.jar` and other
prerequisites before the base unit launcher runs. The Ant run may rewrite a
tracked runtime JAR as a build side effect; that generated binary is not part of
the Phase 1 change.
